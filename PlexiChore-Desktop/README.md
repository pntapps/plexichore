# PlexiChore Desktop (Windows)

PlexiChore turns an Android tablet into a portable monitor for your PC, either as a **mirror** of an existing
screen or as an **extended** second display, over **USB** or **Wi‑Fi**. This repository holds the Windows host:

* **PlexiChore.App** (`src/PlexiChore.App`): the WPF tray app ("PlexiChore Desktop"). It starts with Windows,
  shows status and connected tablets, keeps USB working through adb, approves Wi‑Fi pairing, manages the
  virtual-display driver and settings.
* **PlexiChore.Engine** (`src/PlexiChore.Engine`): the streaming core (TCP/UDP networking, screen capture,
  H.264/MJPEG encoding, touch/pen input injection). The App hosts it through the contract in
  `src/PlexiChore.Engine/Contracts.cs`.

The wire protocol shared with the Android and macOS apps is in [`../PROTOCOL.md`](../PROTOCOL.md).

## Architecture

```
┌────────────────────────── PlexiChore.App (WPF, per-monitor DPI v2, unelevated) ──────────────────────────┐
│ App.xaml.cs        single instance (mutex + activate event), --minimized, tray, pairing popups, logging    │
│ Views/             FluentWindow (WPF-UI) · Home · Extended display · USB · Settings · About · PairingWindow │
│ ViewModels/        MainViewModel (CommunityToolkit.Mvvm) · SessionViewModel · AdbDeviceViewModel          │
│ Services/                                                                                                 │
│   ServerHost         owns IPlexiServer: start/pause/restart, options from settings (restart deferred while  │
│                      a tablet is connected)                                                               │
│   Adb/AdbManager     finds adb, polls `adb devices -l` every 2 s, applies `adb reverse tcp:47800 tcp:47800`│
│                      on every authorized device, re-checks every 15 s, one-click platform-tools download  │
│   SettingsService    %APPDATA%\PlexiChore\settings.json (HostId GUID, trusted tablets, prefs)             │
│   StartupRegistration HKCU\…\Run\PlexiChore = "<exe>" --minimized                                         │
│   FirewallService    elevated netsh rules TCP 47800 / UDP 47801 (only on click)                           │
│   FileLogger         %LOCALAPPDATA%\PlexiChore\logs\plexichore-yyyyMMdd.log (7 days)                      │
│   TrayService        H.NotifyIcon tray: Open · connected tablets · Pause/Resume · Quit · notifications     │
│ VirtualDisplay/                                                                                           │
│   VirtualDisplayDriverProvider : IVirtualDisplayProvider  ← Engine calls this for "extend"                │
│   VddInstaller · VddSettingsFile · VddPipeClient · VddDeviceDetector · DisplayNative · DisplayLayout      │
└──────────────────────────────────────────────┬────────────────────────────────────────────────────────────┘
                                               │ new PlexiServer(vddProvider, logger)
┌──────────────────────────────────────────────▼──────────────── PlexiChore.Engine ────────────────────────┐
│ TCP 47800 server · UDP 47801 beacon · capture (DXGI) · encode (Media Foundation) · input injection      │
└──────────────────────────────────────────────────────────────────────────────────────────────────────────┘
```

The App is **per-monitor DPI aware v2** (`app.manifest`). This is required by the Engine, so GDI/DXGI
coordinates and injected touch input are physical pixels on the captured monitor.

## Build

Requirements: Windows 10 1809+ and the .NET 10 SDK. Visual Studio and the WDK are not needed.

```powershell
dotnet build PlexiChore.slnx               # App + Engine + tools + tests
dotnet test  tests\PlexiChore.App.Tests    # parsing / layout / settings / installer-logic unit tests
dotnet run --project src\PlexiChore.App    # launch (add -- --minimized to start in the tray)
```

Design-time only: `dotnet build src\PlexiChore.App -p:UseEngineStub=true` compiles the App against
`Contracts.cs` and a fake server (`EngineStub/PlexiServerStub.cs`, with `PLEXICHORE_DEMO=1` for a fake session).
Use it if the Engine project is temporarily broken.

### Packaging

```powershell
.\publish.ps1                 # self-contained single-file win-x64 → dist\PlexiChore.exe
.\publish.ps1 -Installer      # + Inno Setup 6 installer → dist\PlexiChoreSetup-<ver>.exe
```

`installer/PlexiChore.iss` installs to Program Files and creates Start-menu and (optional) desktop shortcuts.
It can also add the Start-with-Windows entry (HKCU Run, `--minimized`) and the firewall rules (TCP 47800,
UDP 47801), and it removes the rules on uninstall. The app icon `src/PlexiChore.App/Assets/PlexiChore.ico` is
generated by `tools/make-icon.ps1`.

## Usage

PlexiChore starts in the tray (or shows its window on first launch). Closing the window keeps it running in the
tray, and **Quit** from the tray menu exits it. The Home page shows *Ready — waiting for tablet*, then a card per
connected tablet with transport, mode, resolution, frame rate, bitrate, round-trip latency, encode time and
**Disconnect**.

### USB (recommended: lowest latency)

1. On the tablet, enable **Developer options**, then **USB debugging**.
2. Plug it in and accept **Allow USB debugging?** (tick *Always allow*).
3. Open PlexiChore on the tablet. It finds the PC at `127.0.0.1:47800` and labels it **USB**.

The USB page shows the adb that PlexiChore found and every device it detects. It looks first in
`%LOCALAPPDATA%\PlexiChore\platform-tools`, then the Android SDK (`ANDROID_HOME`, `%LOCALAPPDATA%\Android\Sdk`),
then `PATH`. If adb is missing, **Download adb** fetches Google's
`platform-tools-latest-windows.zip`. Unauthorized devices come with a hint. PlexiChore never kills or restarts
your adb server, and wireless-debugging devices (`adb pair` / `adb connect`) are handled the same way.

### Wi‑Fi

1. Put the PC and the tablet on the same network. Click **Settings → Windows Firewall → Add firewall rules**
   once (one UAC prompt), or tick the firewall option in the installer.
2. Open PlexiChore on the tablet. The PC appears through the UDP 47801 beacon. You can also type the PC's IP,
   which the Home page shows.
3. The first time, a topmost **approval popup** on the PC shows the tablet name and a 4‑digit code. Check that
   the code matches the tablet and click **Approve**. The tablet is added to **Trusted tablets**
   (Settings) and won't be asked again. You can remove it there at any time. Turning off *Require approval*
   lets any tablet on the network connect.

### Extended display

Extend mode needs a virtual monitor. On **Extended display**, click **Install driver** to download and install the
signed open-source [Virtual Display Driver](https://github.com/VirtualDrivers/Virtual-Display-Driver) (MIT),
with one UAC prompt. From then on, a tablet that requests *Extend* gets its own monitor at its resolution,
placed left/right/above/below your main screen as it asked. It disappears when the tablet disconnects. Without
the driver, tablets fall back to mirroring. **Repair**, **Restart** and **Uninstall** are on the same page. See
[`driver/README.md`](driver/README.md) for why we don't ship a custom driver, the exact install mechanism and
how to test it.

### Files and locations

| What | Where |
|---|---|
| Settings (HostId, trusted tablets, prefs) | `%APPDATA%\PlexiChore\settings.json` |
| Logs | `%LOCALAPPDATA%\PlexiChore\logs\` |
| Downloaded adb | `%LOCALAPPDATA%\PlexiChore\platform-tools\` |
| Driver payload / scripts | `%LOCALAPPDATA%\PlexiChore\vdd\` |
| Virtual display settings | `C:\VirtualDisplayDriver\vdd_settings.xml` |
| Autostart | `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\PlexiChore` |
